## 🌟 Bir baxışda

**Udolor AZ** — qeydiyyatdan keçdiyiniz Udemy kurslarını rahat şəkildə yükləməyə imkan verən masaüstü tətbiqidir. Glassmorphism üslubunda tünd qradient interfeys, neon vurğular və yumşaq animasiyalarla təqdim olunur. Tam Azərbaycan dilində, qrammatik baxımdan diqqətlə yoxlanılmış mətnlərlə.

> Bu layihə [heliomarpm/udemy-downloader-gui](https://github.com/heliomarpm/udemy-downloader-gui) layihəsinin Azərbaycan dilinə uyğunlaşdırılmış və tamamilə yenidən dizayn olunmuş versiyasıdır.

## 🚀 Quraşdırma

### Mənbədən qurma

```bash
# 1) Repozitoriyanı klonlayın
git clone https://github.com/goshgarhasanov/udolor_az.git
cd udolor_az

# 2) Asılılıqları yükləyin
npm install

# 3) Tətbiqi işə salın
npm start
```

### İnkişafçı rejimi (DevTools açıq)

```bash
npm run dev
```

### Quraşdırıcı paketi yaratmaq

```bash
npm run build           # cari platforma üçün
npm run build:w32       # Windows 32-bit üçün
```

> 📦 Hazırlanmış quraşdırıcılar `dist/` qovluğunda yerləşəcək.

## 🔑 Necə istifadə etməli

| Addım | İzah |
| :---: | --- |
| **1️⃣** | Tətbiqi açın — Udolor AZ avtomatik olaraq Azərbaycan dilində açılacaq |
| **2️⃣** | Giriş üsulunu seçin (adi hesab və ya **Udemy Business**) |
| **3️⃣** | **Etibarnaməni al** düyməsi ilə Udemy hesabınıza daxil olun |
| **4️⃣** | Kursunuzu **Kurslar** bölməsindən və ya axtarış vasitəsilə tapın |
| **5️⃣** | **Yüklə** düyməsini basın və **Yükləmələr** bölməsindən izləyin |

> 💡 *İpucu: Access Token-i necə əldə etmək lazım olduğunu giriş səhifəsindəki keçiddən öyrənə bilərsiniz.*

```
udolor_az/
├── app/
│   ├── assets/         # şəkillər, ikonlar, Semantic UI
│   ├── core/services/  # Udemy API, m3u8 servisləri
│   ├── css/            # xüsusi tema (style.css)
│   ├── helpers/        # parametrlər, ui yardımçıları
│   ├── locale/         # tərcümələr (az.json + 23 başqa dil)
```
